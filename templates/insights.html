How accurate is it?

Measured on - applications the model never saw during training.

Which model was chosen?

Three models were trained and scored with 5-fold cross-validation (five practice exams on the training data). The best one was kept. The test score is the final exam.

Where does it go wrong?

Each application in the test set lands in one of four boxes. Wrongly approving a risky loan is the costly mistake for a lender.

What does it pay attention to?

Share of the model's decision that each input is responsible for.
